# geo-ingitdb on GitHub fixture

Byte copies, at commit `2a84199bcab79744b48ec529e48559a89a4b8851` of
[ingitdb/geo-ingitdb](https://github.com/ingitdb/geo-ingitdb), of the files the browser
reads for Act 4: `.ingitdb/settings.yaml`, `.ingitdb/root-collections.yaml`, each collection's
`.collection/definition.yaml` (saved here as `<collection>.definition.yaml`) and its
published default view `$ingitdb/<collection>/<collection>.ingr`. Data: GeoNames and
World Bank SP.POP.TOTL, both CC BY 4.0, modified; see that repository's `DATA-LICENSE.md`.

The OVDB descriptor `geo-github.ovdb.yaml` and the three Act 4 queries are copies from
[datatug/datatug-demo-project](https://github.com/datatug/datatug-demo-project)
(`demo-project-1/fixtures/ovdb` and `demo-project-1/queries/reference`).
